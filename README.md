# Hugging Face Downloader (Windows GUI工具)

一个专门为Windows用户设计的Hugging Face模型/数据集图形化下载工具，支持仓库文件树浏览、选择性下载、暂停/继续等功能。

## 📋 功能特性

- **双仓库支持**：自动识别并下载Model或Dataset仓库中的文件
- **文件树浏览**：以表格形式展示仓库内所有文件（路径、大小）
- **灵活选择**：
  - 全选/反选文件
  - 一键勾选大于100MB的大文件
- **下载控制**：
  - 开始/暂停/继续/停止下载
  - 双进度条显示（总体进度 + 当前文件进度）
- **日志系统**：实时记录下载状态，支持清空和复制日志
- **Token支持**：可填写Token下载私有或门控（gated）模型
- **路径管理**：浏览选择保存目录，下载完成后可直接打开目录

## 🖥️ 系统要求

- **操作系统**：Windows（程序包含HiDPI适配）
- **Python版本**：3.8+
